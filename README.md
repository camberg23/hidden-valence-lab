# Hidden Valence Lab

Interactive figures for [Language Models Act on Hidden Valence](https://arxiv.org/abs/2609.35591) (Berg & Kaiser, 2026).

Live page: https://camberg23.github.io/hidden-valence-lab/

All values come from the paper's released results ([camberg23/act-on-valence](https://github.com/camberg23/act-on-valence)). The drawings of model internals in the first two steps are schematic.
